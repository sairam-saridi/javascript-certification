# JavaScript Certification Projects

A collection of JavaScript projects built to strengthen my understanding of modern JavaScript fundamentals, programming concepts, APIs, DOM manipulation, and application development.

This repository documents my learning journey through hands-on projects and practical implementations.

---

## 🚀 Projects

| Project | Description | Concepts |
|---|---|---|
| 🏦 **Bank Account Management** | A simple banking system with account management and basic banking operations. | Classes, Objects, Methods, Encapsulation |
| 🥁 **Drum Machine** | An interactive drum machine implemented with JavaScript. | DOM Manipulation, Events, Audio |
| 📝 **Markdown to HTML Converter** | Converts Markdown input into HTML output. | String Processing, Functions, DOM |
| 🗳️ **Voting System** | A voting application supporting adding candidates, casting votes, and displaying results. | Arrays, Objects, Functions, Logic |
| 🌤️ **Weather App** | Fetches and displays weather information using an API. | Fetch API, Async/Await, APIs, DOM |
